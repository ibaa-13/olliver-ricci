Gestures

  • Click empty space: create a vertex.
  • Drag vertex → vertex: create an edge.
  • Double-click: select a vertex or edge.
  • Selected vertex + drag: move it.
  • Drag on empty space: box-select elements.
  • Ctrl/Shift + box: add to the selection.
  • Delete / Backspace: delete the selection.
  • Esc: clear the selection.
  • R: compute the selected curvature.
